Key Files (⭐)
==============

1. index.html (33KB)
   - Single-file web dashboard
   - Modern dark theme UI
   - Tailwind CSS + Alpine.js + Chart.js (CDN)
   - 8 major sections:
     ✓ Navigation header
     ✓ Search bar
     ✓ Metrics cards (4)
     ✓ Trending products
     ✓ Price intelligence chart
     ✓ Sentiment analysis chart
     ✓ Risk assessment
     ✓ Data ingestion stats

2. static-server.ts (5.3KB)
   - Express.js server
   - Serves index.html
   - Proxies /api/* to backend
   - SPA routing support
   - Health check endpoint
   - Graceful shutdown

3. start-all.sh (2.8KB)
   - Starts API (port 3000)
   - Starts Dashboard (port 3001)
   - Environment setup
   - Graceful cleanup

Quick Commands
==============

Install:
  $ npm install

Start Dashboard Only:
  $ npm run dashboard:dev

Start Everything:
  $ npm run start:all

Visit:
  http://localhost:3001

Health Check:
  http://localhost:3001/health

Technology Stack
================

Frontend (CDN):
  • Tailwind CSS 3.x
  • Alpine.js 3.x (15KB)
  • Chart.js 4.4

Backend:
  • Express.js 4.18
  • TypeScript 5.3
  • Node.js >= 18
