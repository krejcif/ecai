Backend:
- Express.js 4.18
- http-proxy-middleware 2.0
- TypeScript 5.3
- Node.js >= 18

QUICK START
===========

1. Install dependencies:
   npm install

2. Start everything:
   npm run start:all

3. Open browser:
   http://localhost:3001

4. Or start dashboard only:
   npm run dashboard:dev

CONFIGURATION
=============

Environment Variables:
- DASHBOARD_PORT=3001 (default)
- API_URL=http://localhost:3000 (default)
- NODE_ENV=development

Config File:
- src/dashboard/config.json
